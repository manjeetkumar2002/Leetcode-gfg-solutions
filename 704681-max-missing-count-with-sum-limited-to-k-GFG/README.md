# [Max Missing Count with Sum Limited to K](https://www.geeksforgeeks.org/problems/raju-and-coins1932/1?sortBy=submissions&category%255B%255D=Greedy&page=2&difficulty%255B%255D=0)
## Easy
Given an array arr[] of integers and an integer k. You need to find the maximum number of distinct positive integers that can be selected such that: The selected integers are not present in the array.  The sum of the selected integers does not exceed k .  Return the maximum possible count of such integers.Examples:Input: k = 14, arr[] = [4, 6, 12, 8]
Output: 4
Explanation: The integers 1, 2, 3 and 5.Input: k = 25, arr[] = [5, 6, 7, 8]
Output: 5
Explanation: The integers are 1, 2, 3, 4 and 9.
