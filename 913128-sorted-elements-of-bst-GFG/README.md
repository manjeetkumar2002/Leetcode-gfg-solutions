# [Sorted Elements Of BST](https://www.geeksforgeeks.org/problems/sorted-elements-of-bst/1)
## Easy
You are given the&nbsp;root node of a Binary Search Tree (BST), Return the elements of the tree in sorted order.
Examples :
Input: root = [10, 5, 18, N, N, 12]Output: [5, 10, 12, 18]Explanation: The Sorted order of BST is 5, 10, 12, 18.
Input: root = [22, 12, 30, 8, 20]Output: [8, 12, 20, 22, 30]Explanation: The Sorted order of BST is 8, 12, 20, 22, 30.
Constraints:1&nbsp;≤ &nbsp;number of nodes&nbsp;≤ &nbsp;1051&nbsp;≤ &nbsp;node-&gt;data&nbsp;≤&nbsp; 105
