# [Pair Sum in BST](https://www.geeksforgeeks.org/problems/find-a-pair-with-given-target-in-bst/1)
## Medium
Given a Binary Search Tree(BST) and a target. Check whether there's a pair of Nodes in the BST with value summing up to the target.&nbsp;Examples:Input: root[] = [7, 3, 8, 2, 4, N, 9], target = 12Output: TrueExplanation: In the binary tree above, there are two nodes (8 and 4) that add up to 12.Input: root[] = [9, 5, 10, 2, 6, N, 12], target = 23Output:&nbsp;FalseExplanation: In the binary tree above, there are no such two nodes exists that add up to 23.
