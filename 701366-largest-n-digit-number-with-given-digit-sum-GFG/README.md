# [Largest n Digit Number with Given Digit Sum](https://www.geeksforgeeks.org/problems/largest-number-with-given-sum-1587115620/1?sortBy=submissions&category%255B%255D=Greedy&page=1&difficulty%255B%255D=0)
## Easy
Given two integers n and s. find the largest possible number that can be formed using exactly n digits such that sum of the digits equals s.&nbsp;

If it is not possible to construct such a number, return "-1".
Return the result as a string. 

Examples:
Input: n = 5, s = 12
Output: 93000
Explanation:
Sum of elements is 12. Largest possible 5 digit number is 93000 with sum 12.

Input: n = 3, s = 29
Output: -1
Explanation:
There is no such three digit number whose sum is 29.
Constraints:1 ≤ n ≤ 1040 ≤ s ≤ 9*104
