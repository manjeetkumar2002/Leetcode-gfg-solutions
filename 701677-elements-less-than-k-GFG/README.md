# [Elements Less Than K](https://www.geeksforgeeks.org/problems/elements-less-than-k/1)
## Easy
Given an array arr[] and an integer k, return all elements of arr that are less than k. The elements in the returned vector should appear in the same order as in the original array. Note: If no element is less than k, return an empty vector.Examples :Input: arr[] = [5, 3, 6, 1, 3], k = 4
Output: 3 1 3
Explanation: The elements less than 4 are 3, 1, 3, and their original order is preserved.
Input: arr[] = [5, 6, 7], k = 5
Output: []
Explanation: There is no element less than 5.
