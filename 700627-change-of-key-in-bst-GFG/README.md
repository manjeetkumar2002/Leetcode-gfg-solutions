# [Change of Key in BST](https://www.geeksforgeeks.org/problems/implement-change-key-in-bst/1)
## Easy
Given a Binary Search Tree (BST) and two integers oldVal and&nbsp;newVal, change the key value oldVal to newVal while preserving the Binary Search Tree property.
Examples :
Input: root[] = [50, 30, 70, 20, 40, 60, 80], oldVal = 40, newVal = 10 Output: BST should be modified to followingExplanation: The node with value 40 is removed from the BST. The value 10 is then inserted at the appropriate position.
Constraints:1 ≤ Number of Nodes in tree ≤ 105
